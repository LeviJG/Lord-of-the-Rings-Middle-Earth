# Hand-written resources

Most JSON is generated by datagen (`src/client/java/.../datagen`, output in
`src/main/generated`). What remains hand-written under `src/main/resources` is
listed here with the reason it is not generated. A file whose content is
mechanical -- derivable from the registries or the family lists -- belongs in a
provider instead; add it there, not here.

## Assets

- **Blockstates (192) and block models (201).** Blocks whose shape or state
  logic no stock generator expresses. Examples: gates and Dwarven doors
  (connected-border plugin, see `LOTRConnectedBorderTypes`), wall banners,
  beds, torches and double torches, mugs, goblets, cups and plates, troll
  totems, treasure piles, weapon racks, the kebab stand, the table of
  command, the Utumno portal pieces, the three overlay grasses, reeds and
  corn, riverweed, the grapevine post and the clovers. `LOTRModelProvider`
  names the hand-written ones where it skips them.
- **Item definitions (274) and item models (981).** Items whose look needs
  more than one flat sprite:
  - `select` definitions for bow and crossbow pull stages;
  - the large in-hand models (legendary swords, polearms, pikes braced,
    carried and in hand, lances, spears);
  - `composite` beds and `special` chests;
  - block items drawn with their block model;
  - the flat sprites those definitions point to.
  Plain flat items (one sprite of their own texture) are generated:
  `LOTRFlatItemModels`.
- **Equipment assets (92).** Per-material layer data: which of
  humanoid / humanoid_leggings / horse_body each armour material has, dye
  defaults, and borrowed textures (the diamond horse armour uses vanilla's).
  This is data about each material, not derivable from anything, so restating
  it in Java would only move it.

## Data

- **Tags (132).** Hand-picked lists: the `repairs_*` ingredient tags, faction
  and ore-dictionary equivalents, entity and damage-type tags. Tags derived
  from block families are generated (`LOTRBlockTagProvider`,
  `LOTRItemTagProvider`).
- **Recipes (219).** Most recipes are generated (`LOTRTranscribedRecipes`,
  `LOTRMovedRecipes`, `LOTRRecipeProvider`). The ones left here need what
  the recipe helpers cannot write:
  - 126 drinks, whose results carry drink components (vessel, strength);
  - 36 with ingredient alternatives (a list for one slot);
  - 57 with special recipe types: transmute, dye (including the feather
    dye and the leather hat's), hat feather, pipe dye, poison drink.
- **Damage types (2), instrument (1).** Dynamic-registry entries; no
  provider is set up for these registries.
